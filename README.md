## 📋 Descripción

Tienda virtual de ropa desarrollada en **PHP puro con arquitectura MVC**. Incluye catálogo de productos, carrito de compras, checkout, gestión de pedidos y panel de administración.

---

## ✨ Características

- 🛍️ **Catálogo de productos** con filtros por categoría
- 🛒 **Carrito de compras** persistente
- 💳 **Checkout** con validación de datos
- 📧 **Envío de emails** de confirmación
- 👤 **Gestión de usuarios** con registro y login
- 📦 **Panel de administración** para productos y pedidos
- 🎨 **Diseño responsive** con Bootstrap 5
- 🔒 **Sesiones seguras** y validaciones

---

## 🛠 Stack Tecnológico

- **PHP 8+** — Backend MVC puro
- **MySQL 8+** — Base de datos
- **Bootstrap 5** — UI responsive
- **JavaScript** — Interactividad
- **PHPMailer** — Envío de correos
